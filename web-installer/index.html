● Red Button installieren

  1. XIAO ESP32-S3 per USB-Datenkabel anschließen.
  2. Chrome oder Edge verwenden und auf „Installieren“ klicken.
  3. Den USB/JTAG-Port auswählen. Bei Problemen BOOT halten, RESET kurz drücken und BOOT loslassen.
Dieser Browser unterstützt Web Serial nicht. Bitte Chrome oder Edge verwenden.

Eine Neuinstallation kann Einstellungen löschen. Spätere Updates sind im Geräte-Webinterface über firmware.bin möglich.
